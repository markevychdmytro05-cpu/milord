# Швидкість і точність старту

## Що оптимізовано 26.09.2026

- Видалено секундну паузу між завантаженням сторінки та наступною перевіркою кнопки.
- Перед першим оновленням у момент продажу немає двох записів у JSON.
- Остання секунда перед стартом звільнена від CDP-перевірок і записів на диск.
- Після завантаження готова кнопка перевіряється одразу; подальші зміни DOM відстежує
  MutationObserver. Перевірка видимості через CSS додатково працює на кадрах браузера.
- Перевірка стану та DOM-клік виконуються за один виклик у браузері; запис наміру
  перед ним залишається обов’язковим.
- Видалено серію оновлень раз на секунду. Повтори виконуються тільки без кнопки,
  черги чи перевірки сайту, з паузою щонайменше 5 секунд після завершення завантаження.
- Наступне оновлення не запускається, поки попереднє ще виконується.
- Дата у формі та журналі завжди Europe/Kyiv. Типове значення — найближчі 10:00.

## Локальний вимір

Команда: `npm run benchmark`. Локальна HTML-сторінка, Chrome 154.0.8037.57 у headless-режимі.
Мережева активність заблокована; запитів до НБУ/AdsPower не було.

Вимірювався час від увімкнення кнопки до виконання її click-обробника, включно з
поверненням у ядро програми та записом наміру на диск.

## Чому о 10:00 кнопки ще може не бути

Можливі причини: різниця годинників, фактичне відкриття продажу після номінального часу,
застаріла відповідь кешу, затримка обробки запиту. Для конкретного запуску НБУ причину
не встановлено. Якщо HTML не містить кнопки й сайт не додає її динамічно, потрібен
повторний запит; локальний спостерігач цього не замінює.

Старт чекає локального дедлайну та обережної оцінки серверного часу. Заголовок HTTP Date
має секундну точність, тому старт може запізнитися приблизно на залишок секунди й затримку
мережі. Цей механізм не означає мілісекундної синхронізації сервера. За неможливості
прочитати коректний Date використовується локальний годинник; точний час ОС залишається важливим.

При перевантаженні сайту програма чекає відповідь поточного оновлення. Навігаційний таймаут
зараз 20 секунд; помилка завершить завдання, а не запустить паралельні запити.
Автоматичного «влучення» в невідоме вікно доступності сервера чи гарантії покупки немає.
