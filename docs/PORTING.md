## Свідомі зміни поведінки

- Режим спостереження нічого не додає в кошик. Оригінальний README називав dry run
  сценарій із реальним натисканням; тут режими явно розділені.
- Невідомий стан авторизації призупиняє кліки.
- Черга та перевірки сайту не запускають нові покупки.
- Ліміт кліків і період спостереження не скидаються при оновленні документа.
- Після втрати зв’язку з невідомим результатом немає автоматичного повторного запуску.
- Скасування перевіряється перед натисканням; уже відправлену браузеру дію відкликати неможливо.
- HTTP Date — оцінка часу, а не гарантія точного старту. Значення заголовка мінус час
  отримання використовується як обережна оцінка зміщення; старт чекає також локального дедлайну.
- Серію оновлень раз на секунду вилучено. Мінімальний інтервал між завершенням завантаження
  та наступним оновленням — 5 секунд, лише коли кнопки немає і немає черги або перевірки.
- MutationObserver реагує на появу кнопки без мережевого опитування. Перевірка актуального
  стану та `button.click()` виконуються за один виклик у браузер, як DOM-клік оригінального розширення.
- Остання секунда перед стартом не містить перевірок через CDP або записів на диск;
  перший запис наміру натискання залишається обов’язковим.
- Дата у формі та журналі завжди за Києвом, а не в локальному поясі комп’ютера.
- Ми не переносили логотип НБУ, шрифти, стилі та банер оригінального розширення.
