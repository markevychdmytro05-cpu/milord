# «Успіх» Cloudflare та «Очікування» покупки — 26.09.2026

## Що вдалося встановити

Користувач показав успішний віджет Cloudflare поруч із кнопкою «Очікування». Це не є доказом блокування автоматизації: завершення перевірки та результат додавання в кошик — різні стани.

У локальному журналі завдання зафіксовано одну спробу натискання, повідомлення про перевірку та завершення 120-секундного вікна спостереження з невідомим результатом. Відповідь серверної перевірки токена і причина відмови, якщо вона була, в журналі відсутні.

Read-only підключення до вже відкритого профілю №7 показало сторінку товару 1086: вхід виконано, кнопка «Купити» доступна, віджетів капчі вже немає, підтвердження кошика на товарній сторінці немає. Стан зі скриншота на момент спостереження вже змінився. Ні кліків, ні оновлень, ні навігації ця діагностика не виконувала.

У публічному [скрипті магазину](https://cdn-nbu.solomono.net/bank/js/product.min.js) успішний callback Turnstile позначає віджет класом `success` і запускає власний обробник додавання. Кнопка з класом `clicked` та спінер означають обробку додавання; магазин має власні запити перевірки черги. Код callback лише прочитано, він не викликався діагностикою. Серверну причину затримки або можливу різницю між ручною й автоматичною спробами за цими даними встановити не можна.

## Виправлення бізнес-логіки

- Додано `purchasePending`: розпізнавання вже надісланої покупки через клас `clicked` і видимий спінер магазину.
- Після зникнення капчі статус оновлюється з «Потрібна перевірка» на очікування відповіді магазину. Раніше він міг залишатися застарілим до тайм-ауту.
- Якщо ручна покупка вже обробляється, бот спостерігає за результатом без часових HEAD-проб, оновлень і нового кліку.
- Якщо попередня ручна операція зникла зі стану очікування без підтвердження кошика, бот завершується з невідомим результатом замість повторної покупки.
- Якщо спостереження за вже надісланою операцією завершилося помилкою або тайм-аутом, результат позначається `interrupted`, а не як звичайна відсутність кнопки.

UI не змінено. Спосіб кліку, fingerprint, токени та роботу Cloudflare не змінено. Гарантії відсутності повторної перевірки чи успішної покупки немає.

## Перевірки

`npm run check`: 78 тестів, TypeScript та збірка. Нові тести покривають завершення капчі при ще активному додаванні, ручну покупку до/після стартового оновлення, тайм-аут і зникнення очікування без результату. Реальна повторна покупка під час цього аудиту не запускалася.
